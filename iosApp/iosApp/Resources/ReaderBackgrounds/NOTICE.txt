BgAdapter uses centerCrop and the filename before its final dot as the name.
The gallery is one horizontal row, 100pt high, with 6pt outer padding and
66 x 88pt items including 2pt inner padding. Its first item selects an image.
Runtime thumbnails decode these original JPGs at display size, keep their
original colors and use aspect-fill cropping. No thumbnail files are written.
Captions have a fixed separate band, may visually truncate at large text
sizes, and expose the full original name to accessibility and tooltips.

Integration and persistence:
- Add this directory as a folder reference so the bundle contains
  ReaderBackgrounds/<original filename>. Do not flatten it into the bundle.
- Built-in selection persists only legado-background:<stable catalog ID>.
  The loader matches a known ID exactly before resolving Bundle.main with
  subdirectory ReaderBackgrounds. Never persist a bundle GUID or bundle URL.
- Imported selection may persist legado-background-file:<UUID>.<extension>.
  The loader accepts one canonical UUID basename (either letter case) and
  one nonempty ASCII alphanumeric extension, rejects slashes, backslashes,
  traversal and additional dots, then reads the unchanged filename under
  Application Support/ReaderBackgrounds/. It never creates or writes files.
- Legacy absolute paths still load through UIImage(contentsOfFile:).
- Unknown identifiers and missing or unreadable images return nil. The strip
  leaves unavailable thumbnails empty and disabled rather than using fake art.
- The strip only emits onImport/onSelect callbacks. Persistence, importing,
  ReaderRenderView integration and project registration belong to the host.
