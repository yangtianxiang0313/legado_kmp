The default sans-serif uses weight 400, width 100, upright. Reader text weight
selects 300/400/700/900 on the same bundled variable font.

CoreText loads the file privately from its descriptor, without process-global
font registration. Only the reader's default body/title and ordinary tip font
use it. Explicit imported fonts retain precedence; missing CJK and other glyphs
use the platform fallback cascade. Battery digits retain their original asset.
No system UI font, preference, book data, or imported font file is replaced.
